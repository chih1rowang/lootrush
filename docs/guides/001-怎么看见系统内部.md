# 导览 001：这套系统怎么"看见里面"

（按第一规则写的文档：不堆术语，每个词先说人话。）

## 这个项目是什么

一个"游戏限时商城"的后端：晚上 8 点上架 5000 份半价礼包，几十万人同时抢，
要求：抢购不超发、付了钱道具必到账、每天钱和货对得上账。

## 看见内部的四个窗口

1. **日志（行车记录仪）**：程序自己记的流水账，在 IDEA 控制台实时滚动。
2. **Zipkin（行程单）**：http://localhost:9411 ，每次请求经过哪、每步几毫秒。
3. **Grafana（心电图）**：http://localhost:3000 ，每秒请求数、耗时、内存的实时曲线。
4. **数据库图形界面**：DBeaver 连 localhost:3308（root/123456），表就是一张张 Excel。
   （注意是 3308 不是常见的 3306，原因见 incidents/001。）

## 第一个"亲眼看"动作

程序跑起来后：
- 浏览器开 http://localhost:8080/ping → 看到 pong
- 开 http://localhost:9411 点搜索 → 刚才那次 ping 出现了一条行程单
- 开 http://localhost:8080/actuator/prometheus → 满屏指标文本（Grafana 画的就是这些数）

三个都成立 = 程序和整套观测系统接通了。
