# NightMarket（限时夜市）游戏限时贩售与抽卡后端 — 产品需求文档

- 版本：v1.0（定稿）
- 日期：2026-10-25
- 决策方式：16 项决策点经逐条点选定案，过程记录于对话

## 1. 一句话定位

游戏"限时夜市"运营活动的后端系统：开售洪峰下库存不超发、付了钱道具必到账、钱货每日可对账。

## 2. 用户与角色

- **玩家**（替身网页扮演）：蹲守限时商品开售、抢购、支付、抽卡、看排行榜。
- **运营**（管理后台）：上架商品、设置库存与开售时间、查订单流水、看对账报表。

## 3. 核心业务流（一个玩家的完整夜晚）

登录 → 刷夜市页等开售（倒计时）→ 整点抢购（成功即锁定库存，每人每件限 1 份）→
模拟支付（可能被作恶开关延迟/重发）→ 背包到账（异步）→ 抽卡十连 → 看排行榜 →
15 分钟不付款：订单自动关闭、库存回补。

## 4. 定案决策（16 项）

| # | 决策点 | 定案 |
|---|---|---|
| 1 | 项目名 | NightMarket（限时夜市） |
| 2 | 货币 | 单货币"钻石"；注册赠送＋模拟充值（充值走支付回调链路） |
| 3 | 限购 | 每人每件商品限购 1 份（联合唯一索引防多单） |
| 4 | 登录 | 用户名＋密码（BCrypt 加盐哈希＋JWT 通行证） |
| 5 | 货架 | 全服统一货架（随机个人货架列入后续可选） |
| 6 | 商品形态 | 单件道具；背包按"道具＋数量"堆叠 |
| 7 | 发货 | 支付回调只改状态＋发消息，道具由消费者异步发放 |
| 8 | 假支付作恶开关 | 三个全做：正常支付／延迟 30 秒回调／重发 3 次 |
| 9 | 抽卡形式 | 单抽＋十连（后端同一接口带次数参数） |
| 10 | 保底 | 硬保底 90 抽必出最高档＋概率公示＋流水不可篡改；软保底列后续可选 |
| 11 | 排行榜 | 累计消费钻石榜（购买＋抽卡计分），常驻，**不发榜奖励**（按"无新闪光点即砍"原则） |
| 12 | 造数 | 排行榜预灌 30 万测试玩家（造数脚本，定位为测试数据工厂，服务跳表规模故事） |
| 13 | 前端 | 7 张页面（见第 7 节），深色游戏风 |
| 14 | 仓库 | GitHub 全公开，含四份事故报告；README 门面（架构图/演示 GIF/压测摘要） |
| 15 | 主动取消订单 | 不做（15 分钟自动关单已覆盖） |
| 16 | 商品状态 | 四态＋倒计时：即将开售／抢购中／已售罄／已结束 |

## 5. 开发铁律与方式约定

**最小循环**：每循环只交付一小块可独立验收的功能，节奏固定为
"说清任务 → AI 写码 → 跑通验收 → 人读懂关键思路 → git 存档"。
循环顺序：全局重命名 NightMarket 与注册登录 → 商品上架 → 抢购主线 → 支付与幂等 →
异步发奖与事务 → 延迟关单与回补 → 对账 → 抽卡 → 排行榜 → 造数与压测调参报告。

**方式约定**（2026-10-25 定案）：
- 代码全部由 AI 编写，人负责读懂关键思路（不复敲）；
- 每循环顺手写自动化测试（AI 写、人读懂意图），作为后续改动的回头路保险；
- 集成 Knife4j 在线接口文档；
- GitHub 仓库即建即推、每循环至少一次提交，公开范围含事故报告；
- 用户每周投入 10h+，可每天推进；项目二 gateflow 暂缓；
- 压测机 32GB 内存，10000 并发同机压测（被压程序＋8 容器＋JMeter）参数据此分配。

## 6. 非功能需求

- 单机 JMeter 压测目标：**10000 并发**（抢购接口为主）；
- 任何情况下超卖为 0、重复发货为 0；
- 每个关键动作：页面上可见、后台表里可查；
- 全链路可观测：日志（含请求追踪号）、Zipkin 行程单、Grafana 曲线。

## 7. 替身网页（7 张页面，深色游戏风）

玩家端 5 页：
1. 登录/注册页（一页两标签）
2. 夜市主页（门面页：顶部导航＋商品卡四态＋大字倒计时＋背景大图）
3. 背包与订单页（两标签：道具含数量／订单含状态流转）
4. 抽卡页（卡池展示＋单抽/十连＋简易开包翻转动画＋抽卡记录弹层）
5. 排行榜页（前 100＋我的排名）

管理端 1 页式（左侧菜单切换）：商品上架表单／订单流水／对账报表。
假支付公司自带 1 张支付确认小页（独立服务）。

视觉规范：深色主题、背景大图＋半透明遮罩、发光渐变点缀；
素材仅用免费可商用图库（Unsplash 等），不使用任何游戏公司官方素材；
Vue3 以 CDN 方式引入，不搭前端工程化构建。

## 8. 明确不做 / 后续可选

- 不做：真实支付、战斗/战力、跨服、手机端适配、主动取消订单、发榜奖励。
- 后续可选：软保底、UP 池、随机个人货架。
